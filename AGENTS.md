# Agent instructions

## Technical documentation

Write technical documentation (README.md, `docs/`, guides, doc comments that explain usage) in ASD-STE100 Simplified Technical English. These rules apply to prose. They do not apply to code, commands, config keys or API names.

- Keep sentences short: at most 20 words in procedures, at most 25 words in descriptions.
- Write procedures as numbered steps. Use the imperative and one instruction for each sentence.
- Use the active voice and simple tenses (present, past, future).
- Write one topic in each paragraph, with a maximum of six sentences.
- Use one term for one thing, and use it consistently. Do not alternate between synonyms such as "model" and "checkpoint".
- Use a single verb instead of a phrasal verb: "start", not "spin up"; "remove", not "get rid of".
- Do not use vague words such as "easily", "simply", "just" or "various".
- Do not omit articles ("the", "a").
- Write notes and warnings as separate, short statements. Put a warning before the step that it applies to.
- Use plain, specific statements instead of marketing language.
